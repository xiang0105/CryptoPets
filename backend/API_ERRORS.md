# API 錯誤碼

後端錯誤會使用固定 JSON 格式：

```json
{ "error": "ERROR_CODE" }
```

驗證錯誤會額外包含 Zod 詳細資訊，方便前端或開發者定位欄位問題：

```json
{ "error": "VALIDATION_ERROR", "details": {} }
```

## 共用錯誤

| 錯誤碼 | HTTP | 說明 |
| --- | ---: | --- |
| `VALIDATION_ERROR` | 400 | 請求內容或查詢參數不符合該 API 的 schema。 |
| `AUTH_REQUIRED` | 401 | 呼叫受保護 API 時沒有帶 bearer token。 |
| `INVALID_AUTH_TOKEN` | 401 | Bearer token 缺失、無效、過期，或內容格式不正確。 |
| `INTERNAL_SERVER_ERROR` | 500 | 未預期的伺服器錯誤。 |
